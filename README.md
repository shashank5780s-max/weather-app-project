# Weather App (Python + PyQt5)
## 📌 Project Overview

This project is a GUI-based Weather Application built using Python and PyQt5.
The application allows users to enter a city name and retrieve the current weather information using the OpenWeatherMap API.

The app displays:

Temperature in Celsius and Fahrenheit

Weather description

Weather emoji representation

## Features

Simple and user-friendly GUI interface

Fetches real-time weather data using API

Displays temperature in °C and °F

Shows weather condition emoji

Handles common HTTP and connection errors

## Technologies Used

Python 3

PyQt5 (GUI framework)

Requests library

OpenWeatherMap API


## ⚙️ Installation
### 1️⃣ Install Python

Make sure Python 3 is installed.

Check using:

python --version
### 2️⃣ Install Required Libraries

Install dependencies using pip:

pip install PyQt5 requests
### ▶️ How to Run the Project

Navigate to the project folder and run:

python weather_app.py

The Weather App GUI will open.

## 🌐 API Used

This project uses the OpenWeatherMap API to fetch weather data.

Website:
https://openweathermap.org/api

## 📸 Application Workflow

Enter a city name

Click Get Weather

The app fetches weather data from the API
